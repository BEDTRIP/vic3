# vic3 — узел проекта (правила для агента, загружаются автоматически)

Проект — моды Victoria 3: узел `vic3` (эта папка, свой git) и четыре репо подпапками, у каждого свой git и свой
`CLAUDE.md` ([[Д.ДОК.1 — где узел проекта|Д.ДОК.1]]):

| папка | что |
| --- | --- |
| `docs/` | документы узла: план и все этапы проекта, сквозные решения, методика; вход — `docs/README.md` |
| `vic3_mods/` | компачи, мегапаки, аддоны, переводы |
| `Economic-and-Financial-Ledgerdemain-Mod/` | форк E&F «Ledgerdemain» |
| `vic3_mods_out/` | внешние источники — ваниль и чужие моды, снимок 1.13; только локально, **руками не править**; `docs/` в нём — репо `vic3_out_docs` (будет) |
| `vic3_tools/` | `v3`, мост `vic3-pc`, плагин навыков |

`_tmp_analysis/`, `_bridge/` — черновики и данные моста, не в git.

## Документы

По методике `docs/methodology/` — её карта `docs/methodology/README.md`. Что где лежит — `docs/README.md`. Правка
методики под проект — коммитом в `docs/methodology/` с решением: это опыт внедрения, его потом изучат.

## git узла

- Ветка `main`. Четыре репо — в `.gitignore` узла: коммит узла их не трогает, у каждого свой коммит.
- Пути — явно (`git add -- <пути>`), рядом может работать другая сессия; сообщение по-русски `<область>: <что>
  (<этап, решение>)`.
- Remote у узла появится, когда пользователь создаст репо `vic3` на GitHub; до того — только локальные коммиты.

Правила git и работы в репо — пока в `vic3_mods/CLAUDE.md` (переедут в узел на шаге 2 этапа ДОК):
