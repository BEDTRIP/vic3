# Чем проверять документы всех репо?

## Решили

Одной командой `v3 docs check` в `vic3_tools`; ядро — `check_docs.py` bee-prom. CI каждого репо проверяет свои ссылки, сквозные — проверка узла с соседями рядом.

## Последствия

- Правила проверки одни на пять репо; раскладка каждого — в его настройке.

## Отвергнуто

- Свой скрипт в каждом репо — копии правил расходятся.
