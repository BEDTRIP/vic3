# Где живёт то, что не принадлежит ни одному репо проекта?

## Решили

Узел — репо `vic3`: рабочая копия `C:\ProjectData\vic3`, она же корень хранилища Obsidian; четыре репо проекта — подпапками в его `.gitignore`.

## Последствия

- В узле — методика, план, все этапы, сквозные понятия и решения, окружение, уроки.
- Облачной сессии узел нужен с GitHub — репо `vic3` создаёт пользователь.
- Ссылки из узла в репо и между репо держит проверка узла с клонами рядом.

## Отвергнуто

- `docs/` внутри `vic3_mods` — он снова стал бы «главным» среди четырёх равных.
- Узел без git (как было) — нет истории и нет облака.
