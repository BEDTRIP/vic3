# Как строить графы источников?

## Контекст

Источник: Сессия обсуждения 29.10 — [[2026-11-07 этап ДОК — документация]], «Ход работы».

## Решили

Ночами и параллельно: один источник или один тип объектов — один агент; общие файлы (карты, план) сводит главная сессия.
