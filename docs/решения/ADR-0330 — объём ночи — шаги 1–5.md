## Контекст

Источник: [[Этап ОБН. Обновление источников]]; [[ADR-0312 — слои графа источника|ADR-0312]]

Рассматривали и отвергли:

- Только 1–4 — пилот ждёт свежий снимок с 7.11, его очередь готова.
- Всё 1–7 — тиражировать механики до разбора пилота рано ([[ADR-0312 — слои графа источника|ADR-0312]] — гипотеза до пилота).

## Решили

Ночь — шаги 1–5 файла этапа: снимок, дамп, `v3 graph all` + `v3 docs check`, отчёт «1.13 → 1.15» артефактом, пилот «стройка» по очереди из [[2026-11-07 этап ДОК — документация|истории ДОК]], шаг 5 (правки методики по пилоту — ночью с пометкой, [[ADR-0323 — правки методики по пилоту — ночью с пометкой|ADR-0323]]). Шаги 6 (тиражирование механик) и 7 (уроки, CI) — днём, после разбора пилота с пользователем.
