# Кто и как обновляет снимок vic3_mods_out?

## Решили

Агент (ночь, шаг 1) заменяет папки источников в `vic3_mods_out` тем, что сейчас лежит на ПК (пользователь 11.11: «просто замена папок»): ваниль — `C:/Games/Steam/steamapps/common/Victoria 3/game` → `.vanillaVIC3`; моды — их папки мастерской Steam (`C:/Games/Steam/steamapps/workshop/content/529340/<id>`) → папка источника out. Копия как есть (зеркало: удалённое у автора удаляется и в out), без правок; `.gitignore` out (`*.dds`, `*.bank`, `*.tga`, `/docs/`) не трогать. Коммит в локальный git out — **один на источник**, сообщение «снимок 1.15: <источник> <версия из metadata>», чтобы `git diff` был разницей версий. Правило «руками не править» — про содержимое; копия не правка.

## Отвергнуто

- Снимок делает пользователь (прежний шаг 1) — пользователь отдал агенту.
