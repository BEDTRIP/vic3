# Как хранить документацию внешних источников в git?

## Решили

`vic3_mods_out/docs/` — клон отдельного репо `vic3_out_docs`, в `.gitignore` out.

## Последствия

- На GitHub — только наш текст; облако видит документацию источников без самих источников.

## Отвергнуто

- Залить out на GitHub приватным — 20 ГБ игры и чужих модов.
