# Из чего и как собирать справочник движка?

## Решили

Из дампа `script_docs` (триггеры, эффекты, модификаторы, цели событий, `on_action`) и `dump_data_types` / `dump_tweakables` — копия в `vic3_mods_out/docs/vanilla/движок/` как снимок 1.13; справочник — таблицы по виду (заметка на вид, большие — по буквам), не заметка на эффект.

## Последствия

- Эффектов около 700, типов модификаторов около 2350 — заметка на каждый захламила бы граф.
- Карточка объекта ссылается на строку таблицы якорем.

## Отвергнуто

- Заметка на каждый эффект и модификатор.
