# Как документировать ваниль и чужие моды, на которых стоит проект?

## Решили

`vic3_mods_out` — git для слежения за изменениями ваниль и чужих модов (только локально, ≈20 ГБ). Документация каждого источника — вне папок модов и ваниль, в `vic3_mods_out/docs/<источник>/` (`vanilla/`, `ef/`, `morgenrote/`…): понятия, механики, код, сравнение с ваниль. `ваниль/` форка и `сводки по модам/` пачки переезжают туда; генератор ваниль — в `vic3_tools`.

## Последствия

- Обновление мода или игры не затирает документы; что поменялось — `git diff` out по `paths` документов.
- `vic3_mods` строит компачи и связки механик анализом этих графов.

## Отвергнуто

- Документы в папках модов — их перезаписывает обновление источника.
