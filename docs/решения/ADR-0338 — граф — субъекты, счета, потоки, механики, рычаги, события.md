# Из каких заметок строится граф игры?

## Контекст

Пилот «стройка» (12.11) описал механику и потоки, но субъекты (казна, строительные сектора) в них — словами:
отдельных заметок на субъекты нет, а генерат (термины, карточки) был под запретом ссылок из текста для человека.
Пользователь 20.11: граф — симулякр игры, связи между понятиями должны быть видны; код игры заметками не
дублировать — для кода есть `v3` (def / refs / winner) и tiger. Типы субъектов — по объектам движка (scope) из
дампа 1.15.2: страна, штат, здание, население, компания, рынок, товар на рынке и в штате, группа интересов, закон,
персонаж. Запрет ссылок на агентские заметки снят в методе (methodology 8442e0a).

## Решили

Шесть типов заметок графа (вид в шапке — `explanation` с тегом типа):

- **Субъект** — объект движка, который хранит и действует: страна, штат, рынок, здание, население, компания,
  группа интересов… Что хранит (счета), кто решает (игрок, ИИ, движок), с кем связан.
- **Счёт** — что субъект хранит и что течёт: деньги казны, золотой запас, долг, кошелёк населения, инвестиционный
  пул, касса здания, запас товара на рынке, очки стройки.
- **Поток** — движение со счёта на счёт: от кого → кому, что, когда, как считается, размер из прогона.
- **Механика** — процесс из потоков и правил вокруг одной цели (стройка, ценообразование, найм).
- **Рычаг** — что меняет поток: закон, технология, метод производства, модификатор, define — карточки генерата и
  справочник движка, отдельных заметок не пишем.
- **Событие** — дискретный толчок: событие, дневник, решение (генератор их пока не собирает).

Связи — ключами шапки (ссылки Obsidian): у потока `from`, `to` (субъекты), `account` (счёт), `levers` (рычаги);
у механики — `flows`; у субъекта — `accounts`; своё поверх чужого — `uses` / `replaces`. В тексте — ссылки на всё,
у чего есть заметка, генерат тоже.

## Последствия

- Код игры заметками не повторяем: строки и эффекты — путём в «Где» и через `v3`.
- Пилот «стройка» переписывается по схеме ([[SRC-27 — Схема графа на пилоте «стройка» — субъекты, счета, потоки|SRC-27]]),
  потом — образец для всех областей этапа «Г».
- Форк и моды в графе — те же типы: новые субъекты и счета (ЦБ, банки, биржа) и потоки с `replaces` на потоки ваниль.
