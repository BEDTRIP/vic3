# Чем сверять потоки пилота?

## Решили

Прогонами в ВМ `vic3-sandbox`: две новые игры за Швейцарию по 10 лет — ваниль (без модов) и мегапак; сейвы — `v3 save`. **Сети у ВМ нет** (пользователь 29.10: Steam иначе обновит моды): адаптер отключён от коммутатора, файлы — через PowerShell Direct.

## Последствия

- Поток с сейвом — «сверено на <прогон>»; без прогона — «не сверено».
- Сеть ВМ не включать.

## Отвергнуто

- Только по файлам — потоки останутся догадкой.
