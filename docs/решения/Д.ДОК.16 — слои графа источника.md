# Какие заметки у графа источника?

## Решили

Пять слоёв и справочник, одинаково у ваниль и мода: **термины** (генерат); **объекты** со связями из файлов, население тоже (генерат, ручной раздел генератор сохраняет); **области реализации** — папки базы данных (каркас генератором, сверху ручной текст); **механики** (агенты по файлам); **потоки** товаров и денег (агенты по наблюдению, сверка сейвом); **справочник движка** (генерат из script_docs). У мода — справочник «что меняет в ванили», ключи `uses` / `replaces`, карточки только добавленных и изменённых объектов с разницей по полям.

## Последствия

- Рабочая гипотеза до пилота «стройка» (шаг 5 этапа); шаблоны правятся по его итогу.
- Объекты — только генерацией: у ваниль их порядка 1500.
- Баланс мерится потоками из сейва; два мода на одном потоке — предмет компача.

## Отвергнуто

- Пересказ кода прозой — устаревает с первым обновлением.
- Без потоков — движение денег и товаров делает движок, в файлах его не видно.
