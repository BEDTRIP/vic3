# Кто правит методику по итогам пилота?

## Решили

Ночь коммитит правки шаблонов и методики сама, каждая — коммит в `docs/methodology/` с пометкой «проверить» и ссылкой на пилот; пользователь смотрит утром по `git log docs/methodology/`.

## Последствия

- Неверную правку утром откатывают новым коммитом.

## Отвергнуто

- Ночью только предложения разделом в файле этапа — утро уходит на перенос.
