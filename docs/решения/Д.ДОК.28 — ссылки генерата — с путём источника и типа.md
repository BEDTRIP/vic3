# Как генерат ссылается на карточки?

## Решили

Всегда с путём источника и типа: `[[vanilla/Здания/Шахта|Шахта]]`. Одинаковые имена в одном типе — ключ в скобках в имени файла.

## Последствия

- Карточки E&F и других модов с теми же именами не делают ссылки ваниль неоднозначными.
- Ссылки руками на карточку — тоже с путём, когда имя не единственное ([[Ссылки]]).

## Отвергнуто

- Ссылки по имени, хвост пути — только при совпадении: с каждым новым источником пришлось бы перегенерировать все.
