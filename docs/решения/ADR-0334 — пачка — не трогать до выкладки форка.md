# Что делать с выложенными сборками пачки, пока форк не выложен?

## Контекст

План всего проекта 20.11 (пользователь: «давай разберёмся, составим план по всему проекту»); выбор — из вариантов с рекомендацией, ответ пользователя 20.11. Варианты: не трогать —
рекомендация; поддерживать на 1.15 на старых E&F и PSC; снять устаревшее.

## Решили

- 21 предмет пачки в мастерской остаётся как есть до выкладки форка; силы — на форк.
