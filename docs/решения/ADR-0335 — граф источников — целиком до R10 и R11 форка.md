# Сколько вкладывать в граф источников до работы над форком?

## Контекст

План всего проекта 20.11 (пользователь: «давай разберёмся, составим план по всему проекту»); выбор — из вариантов с рекомендацией, ответ пользователя 20.11. Варианты: по надобности
форка — рекомендация; сначала полный граф; заморозить ручные механики.

## Решили

- Механики и потоки — по всем источникам, в порядке
  [[ADR-0313 — порядок источников|ADR-0313]]: ваниль целиком → E&F → пачка → аддоны → TechRes+Kuromi; образец —
  пилот «стройка» после приёмки ([[SRC-3 — Разбор пилота «стройка» и принятого ночью 12.11|SRC-3]]).
- R10 и R11 форка — после графа.

## Последствия

- Новый этап [[Этап Г. Граф источников целиком]]: механики ваниль, затем моды.
- Этап «Ф. Форк до 1.15» — техническое обновление форка на 1.15.2 — идёт параллельно: трогает только форк, граф
  ему не нужен (предложение агента 20.11 — пользователь может перенести после графа).
