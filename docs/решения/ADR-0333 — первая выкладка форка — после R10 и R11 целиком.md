# Что должно быть в первой выкладке форка?

## Контекст

План всего проекта 20.11 (пользователь: «давай разберёмся, составим план по всему проекту»); выбор — из вариантов с рекомендацией, ответ пользователя 20.11. Варианты: минимум (окна, панель, баланс) и
обновления после выкладки — рекомендация; R10 и R11 целиком; ранняя скрытая выкладка для игроков.

## Решили

- Первая выкладка «E&F: Ledgerdemain» — после [[Этап R10. Интерфейс и графика|этапов R10]] (интерфейс и вся графика) и R11 (баланс и динамика)
  целиком; урезанной 1.0 нет.

## Последствия

- Порядок форка: Ф → R10 → R11 → R12 (выкладка); R13 — после выкладки, если нужен.
