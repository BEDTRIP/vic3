# Как работать по времени?

## Контекст

План всего проекта 20.11 (пользователь: «давай разберёмся, составим план по всему проекту»); выбор — из вариантов с рекомендацией, ответ пользователя 20.11. Варианты: днём решения и /loop очередью — рекомендация; только
днём с пользователем; ночные очереди крупно.

## Решили

- Днём, с пользователем: ответы на `question`, приёмка задач `review` обзором этапа, нарезка новых задач.
- Без пользователя: `/loop` берёт задачи этапа по «Порядку» ([[Задание агенту (agent brief)]],
  [[Ночная работа (multi-agent night run)]]); прогоны — в ВМ-песочнице

  с `question`, агент берёт следующую.
