# Что остаётся в `vic3_mods`?

## Решили

Компачи, мегапаки, аддоны, переводы. `tools/` пачки и конфиг моста (`bridge.toml`, `tools/pc_bridge`) — к переносу в `vic3_tools` или узел. README компача с «Для мастерской» — продукт (описание в Workshop); документ компача — отдельно.
