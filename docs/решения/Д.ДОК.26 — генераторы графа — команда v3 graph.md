# Чем собирать генерат графов источников?

## Решили

Командой `v3 graph` в `vic3_tools`: общий инструмент для любого мода и источника, код на английском, текст заметок — из русской локализации игры, подписи полей — на языке проекта. Генератор терминов `regen_ld_vanilla_concepts.py` форка переезжает туда же (`v3 graph terms`), вывод тот же байт в байт.

## Последствия

- Пишет в `vic3_mods_out/docs/<источник>/` (репо `vic3_out_docs`); снимок читает из `vic3_mods_out/`.
- В форке генератор терминов убирается, в `docs/код/generators.md` — ссылка на `v3 graph`.

## Отвергнуто

- Генераторы скриптами в форке — их не взять другому моду, копии расходятся.
