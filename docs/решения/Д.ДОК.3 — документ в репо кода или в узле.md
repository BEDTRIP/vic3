# Какие документы лежат в репо, а какие в узле?

## Решили

Понятия, документы кода, находки — в репо того, что описывают. Решения — в репо, чьё понятие воплощают; сквозные — в узле. Номера решений с префиксом этапа (`Д.R10.16`) уникальны по проекту и становятся именами файлов.

## Последствия

- Правило методики «документ в одном коммите с кодом» держится внутри репо.
- Решения форка (почти все) остаются в форке файлами.

## Отвергнуто

- Все решения в узле одной папкой — решение уходит из коммита кода, который его воплощает.
