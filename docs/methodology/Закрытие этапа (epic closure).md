# Закрытие этапа (epic closure)

## Суть

[[Этап (epic)|Этап (epic)]] закрывают, когда всё в нём сделано или перенесено и это проверено; файл уезжает в
[[История (archive)|историю]], в [[План проекта (roadmap)|плане]] строка пропадает — закрытое видно в файле папки истории.

## Правила

1. Каждая [[Задача (issue)|задача]] этапа закрыта (`done`, `wontdo`, закрытый баг) либо перенесена в другой этап (`epic`
   задачи — новый этап, причина — строкой в её ходе). `review` без приёмки — не закрыта.
2. Definition of Done выполнен и проверен.
3. [[Понятие (explanation)|Понятия]] — «Где» по факту, «Открыто» пусто или называет задачу другого этапа; процедуры и документы
   кода — по факту.
4. [[Решение (ADR)|ADR]] этапа: правило из каждого записано в понятии, процедуре или методе; воплощено не до конца — остаток
   в «Открыто» понятия.
5. Ретроспектива: «ошибки агента» и аварии из хода задач, которые пригодятся вне этапа, — [[Урок (lessons learned)|уроками]]; на месте
   действия — строка со ссылкой на урок.
6. Файл этапа → `история/` с «Итогом» сверху — что сделано, цифры, куда что перенесено: `type: history`,
   `kind: epic`, `date` — дата закрытия; закрытые задачи уже лежат в `история/задачи/` — «Итог» ссылается на них.
7. В плане — строку убрать; «Состояние» переписать.

**Не закрывать наполовину.** Осталось звено — выкладка, выбор, проверка — задача остаётся `review` или `blocked` с
тем, чего ждёт. Остаток на отдельную работу — новой задачей со ссылкой из старой.
