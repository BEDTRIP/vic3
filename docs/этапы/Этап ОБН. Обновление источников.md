# Этап ОБН. Обновление источников

## Цель

Граф источников (`vic3_mods_out/docs/`) — на свежей версии игры и модов (пользователь 7.11: игра уже 1.15), с ясным
отчётом, что поменялось с 1.13, — чтобы потом подтянуть форк и пачку
([[Д.ДОК.33 — ДОК на 1.13 — снимок как есть, потом свежая версия|Д.ДОК.33]]). На 1.13 граф записан «как есть» —
[[2026-11-07 этап ДОК — документация|этап ДОК]]; его коммиты — база для разницы.

## Решено (11.11, пользователь — «по рекомендациям»)

- [[Д.ОБН.1 — курс — ОБН, потом форк на 1.15|Д.ОБН.1]] — курс: ОБН, потом форк на 1.15 (игра на ПК — 1.15.0, DLC работают).
- [[Д.ОБН.2 — снимок out — замена папок с ПК|Д.ОБН.2]] — снимок делает агент: замена папок out свежими копиями с ПК, коммит на источник.
- [[Д.ОБН.3 — моды не под 1.15 — на снимке 1.13 с пометкой|Д.ОБН.3]] — нет свежей версии на ПК — остаётся 1.13 с пометкой.
- [[Д.ОБН.4 — дамп и прогоны ночи — на ПК, без ВМ|Д.ОБН.4]] — дамп и прогоны пилота ночью — на ПК, без ВМ (в ВМ не работает видеокарта).
- [[Д.ОБН.5 — объём ночи — шаги 1–5|Д.ОБН.5]] — ночь: шаги 1–5; 6–7 — днём после разбора пилота.
- [[Д.ОБН.6 — хвосты генерата — сводки сверить, аддоны только с ваниль|Д.ОБН.6]] — сводки модов сверить на 1.15; аддоны — только с ваниль.

## Шаги

1. **Снимок** ([[Д.ОБН.2 — снимок out — замена папок с ПК|Д.ОБН.2]], [[Д.ОБН.3 — моды не под 1.15 — на снимке 1.13 с пометкой|Д.ОБН.3]]) — папки out ← копии с ПК (таблица
   «Источники» ниже), зеркалом (`robocopy /MIR`, `.git` и `docs/` out не трогать), коммит в локальный git out — один на
   источник: «снимок 1.15: <источник> <версия>». Версия ваниль — `rawVersion` в
   `C:/Games/Steam/steamapps/common/Victoria 3/launcher/launcher-settings.json` (папки `launcher` в out нет); у мода —
   `supported_game_version` в `.metadata`. Список «обновлён / остался 1.13» — в «Ход».
2. **Дамп движка** ([[Д.ОБН.4 — дамп и прогоны ночи — на ПК, без ВМ|Д.ОБН.4]]) — `script_docs`, `dump_data_types`, `dump_tweakables` без модов, на ПК
   (навык `vic3-sandbox`, локальный режим); результат — `Documents/…/Victoria 3/docs/`, `dump_date` в `graph.toml`.
3. **Пересборка**: `graph.toml` — `version = "1.15"`, у источников на 1.13 — своя пометка, `dump_date`; `v3 graph all`,
   `v3 graph all --check`, `v3 docs check` (из узла). Коммит вывода в `vic3_out_docs` — один на источник.
4. **Отчёт «1.13 → 1.15»** — артефакт: по источникам и типам — добавлено, убрано, изменено (карточки), что
   поменялось в справочнике движка (эффекты, триггеры, модификаторы, defines); отдельно — что трогает форк (`v3 refs`
   по ключам форка, его зависимости CMF и ETF) и компачи пачки; у аддонов — «аддон к X»
   ([[Д.ОБН.6 — хвосты генерата — сводки сверить, аддоны только с ваниль|Д.ОБН.6]]). По отчёту — задачи форка (этап «Форк до свежей версии») и пачки ([[Этап П. Пачка|этап П]]) записать в их файлы
   списком «из отчёта ОБН».
5. **Механики и потоки — пилот «стройка»** — очередь из [[2026-11-07 этап ДОК — документация|истории ДОК]], «Шаг 5»
   (чтение, механика ваниль, потоки ваниль, PSC и E&F, форк, сверка прогоном ваниль без модов на ПК —
   [[Д.ОБН.4 — дамп и прогоны ночи — на ПК, без ВМ|Д.ОБН.4]] вместо ВМ из [[Д.ДОК.30 — пилот сверяется прогонами в ВМ без сети|Д.ДОК.30]]; прогона мегапака нет); правки методики по пилоту — ночью с пометкой
   ([[Д.ДОК.31 — правки методики по пилоту — ночью с пометкой|Д.ДОК.31]]). Прогоны форка на 1.15 не годятся (форк на
   1.13) — пилот форка только по коду и документам, с пометкой.
6. **Тиражирование механик** — днём, после разбора пилота (порядок — [[Д.ДОК.17 — порядок источников|Д.ДОК.17]]).
7. **Уроки и CI** — днём: «ошибки агента» из хода ДОК и истории форка и пачки → `уроки/`; `v3 docs check` в CI всех
   репо. Строку `- run: v3 docs check` в `vic3_tools/.github/workflows/ci.yml` добавляет пользователь (у токена агента
   нет права `workflow`).

## Хвосты генерата (найдено 7.11)

- Сводки модов («Сводка E&F» и др.) — разборы до ДОК, «не сверено»: сверить с «Что меняет в ванили» на свежем снимке
  или убрать устаревшее.
- Карточки модов без русской локализации — с английскими именами; термины E&F — английские (так в моде).
- Сравнение модов — только с ваниль: аддоны и патчи на другой мод показаны как «нет у ваниль»; нужно ли «что меняет в
  <базовом моде>» — решить при отчёте шага 4.
- `v3 graph all` — около 1,5 мин и 9500 заметок; `v3 docs check` из узла — около 45 с.

## Готово, когда

- снимок out — свежая версия (или пометка по каждому невышедшему моду), `graph.toml` — её версия;
- `v3 graph all --check` и `v3 docs check` чистые, в CI всех репо;
- отчёт «1.13 → свежая» опубликован, по нему записаны задачи форка и пачки;
- у ваниль и E&F есть механики и потоки пилота.

## Ночь

Ночь 11.11→12.11 — шаги 1–5 ([[Д.ОБН.5 — объём ночи — шаги 1–5|Д.ОБН.5]]), навык `night-run`, фаза 2; срока нет — до
