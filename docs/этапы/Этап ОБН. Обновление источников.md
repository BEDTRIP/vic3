# Этап ОБН. Обновление источников

## Цель

Граф источников (`vic3_mods_out/docs/`) — на свежей версии игры и модов (пользователь 7.11: игра уже 1.15), с ясным
отчётом, что поменялось с 1.13, — чтобы потом подтянуть форк и пачку
([[Д.ДОК.33 — ДОК на 1.13 — снимок как есть, потом свежая версия|Д.ДОК.33]]). На 1.13 граф записан «как есть» —
[[2026-11-07 этап ДОК — документация|этап ДОК]]; его коммиты — база для разницы.

## Шаги

1. **Снимок** — пользователь: свежая ваниль и моды в `vic3_mods_out/` (коммит локального git out). Какие моды вышли под
   новую версию, какие нет — список в «Ходе»; невышедший остаётся на снимке 1.13 с пометкой.
2. **Дамп движка** заново — `script_docs`, `dump_data_types`, `dump_tweakables` в ВМ (навык `vic3-sandbox`); лучше без
   модов — дамп 13.10 снят с E&F, его записи в справочнике движка.
3. **Пересборка**: `graph.toml` — `version`, `dump_date`, новые и ушедшие источники; `v3 graph all`, `v3 docs check`.
   Коммит вывода — один на источник, чтобы `git diff` и был разницей версий.
4. **Отчёт «1.13 → свежая»** — артефакт: по источникам и типам — добавлено, убрано, изменено (карточки), что
   поменялось в справочнике движка (эффекты, триггеры, модификаторы, defines); отдельно — записи, которые трогают форк
   (`v3 refs` по ключам форка) и компачи пачки.
5. **Механики и потоки** — перенесено из ДОК, шаг 5 (пилот «стройка»: механика и потоки ваниль, PSC, E&F, форк;
   прогоны в ВМ без сети — [[Д.ДОК.30 — пилот сверяется прогонами в ВМ без сети|Д.ДОК.30]]), правки методики по
   пилоту — [[Д.ДОК.31 — правки методики по пилоту — ночью с пометкой|Д.ДОК.31]]. Причина переноса: на 1.13 описывали
   бы то, что меняется.
6. **Тиражирование механик** — перенесено из ДОК, шаг 6 (порядок — [[Д.ДОК.17 — порядок источников|Д.ДОК.17]]).
7. **Уроки и CI** — перенесено из ДОК, шаг 8: «ошибки агента» из хода ДОК и истории форка и пачки → `уроки/`; `v3 docs
   check` в CI всех репо. Строку `- run: v3 docs check` в `vic3_tools/.github/workflows/ci.yml` добавляет
   пользователь (у токена агента нет права `workflow`).

Не в этом этапе: пачка поверх графа (ДОК, шаг 7) — в [[Этап П. Пачка|этап П]], при пересмотре пачки под свежую версию
вместе с ребалансом компачей; известное `docs-check-known.txt` форка (понятия без `status`, решения без воплощения,
номера в коде без решения, понятия старого вида) — в этап форка «до свежей версии» (план, «Этапы»).

## Хвосты генерата (найдено 7.11)

- Сводки модов («Сводка E&F» и др.) — разборы до ДОК, «не сверено»: сверить с «Что меняет в ванили» на свежем снимке
  или убрать устаревшее.
- Карточки модов без русской локализации — с английскими именами; термины E&F — английские (так в моде).
- Сравнение модов — только с ваниль: аддоны и патчи на другой мод показаны как «нет у ваниль»; нужно ли «что меняет в
  <базовом моде>» — решить при отчёте шага 4.
- `v3 graph all` — около 1,5 мин и 9500 заметок; `v3 docs check` из узла — около 45 с.

## Готово, когда

- снимок out — свежая версия (или пометка по каждому невышедшему моду), `graph.toml` — её версия;
- `v3 graph all --check` и `v3 docs check` чистые, в CI всех репо;
- отчёт «1.13 → свежая» опубликован, по нему записаны задачи форка и пачки;
- у ваниль и E&F есть механики и потоки пилота.
