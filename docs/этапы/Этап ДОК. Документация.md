## Граф источника

Пять слоёв и справочник; одинаково у ваниль и у каждого мода ([[Д.ДОК.16 — слои графа источника|Д.ДОК.16]] — рабочая гипотеза до пилота, шаг 5).

| слой | что | заметка | кто пишет |
| --- | --- | --- | --- |
| **термины** | что видит игрок (`concept_*`) | глоссарий | генерат (614 у ваниль, как сейчас в форке) |
| **объекты** | здания, методы и их группы, товары, законы, технологии, группы интересов, компании, черты; **население** — типы, страты, потребности, пакеты покупок | карточка: имя из локализации, ключ в `aliases`, главные поля, **связи из файлов** (здание → группы методов → методы → товары; закон → группы интересов; технология → что открывает); ручной раздел «зачем в механике» генератор сохраняет | генерат `v3` |
| **области реализации** | папка базы данных (`common/buildings`…): что хранит, ключи, как сливается при моддинге, какие механики её используют | документ кода папки | каркас генератор, сверху ручной текст |
| **механики** | процесс поперёк файлов (стройка, цена, потребление) | «Суть», «Как работает» (цикл, формулы, defines), «Рычаги» (чем скрипт влияет, что зашито в движке), «Стоимость» (скорость), «Где», «Не выяснено» | агенты по файлам |
| **потоки** | кругооборот: субъекты (население по стратам, здание, компания, казна, рынок, инвестиционный пул, банк, заграница) — узлы, потоки (зарплата, дивиденды, налоги, потребление, закупки, стройка, субсидии, торговля, долг) — рёбра | заметка на поток: от кого → кому, что, **когда** (тик), как считается (движок / скрипт, формула), рычаги, **как увидеть в сейве или логе**, на каком сейве сверено; одна обзорная схема кругооборота | агенты по наблюдению (сейвы, логи, прогоны, script_docs); до сверки — «не сверено» |
| справочник движка | триггеры, эффекты, модификаторы, `on_action` | таблицы из дампа script_docs | генерат |

- **Счёт ваниль 1.13** (верхнеуровневые записи, грубо, 29.10): здания 111, методы 420, группы методов 184, товары 53,
  законы 126, технологии 178, виды компаний 220, черты 121 — порядка 1500 карточек одной ваниль. Поэтому объекты —
  только генерацией.
- Скриптовые эффекты (≈700), значения скрипта (≈235), типы модификаторов (≈2350) — не карточками, а справочниками.
- **Почему потоки, а не пересказ кода**: то, что в скриптах, агент читает сам (карточки, `v3 def` / `refs`), пересказ
  устаревает; движение денег и товаров делает движок, в файлах только ручки — его выясняют наблюдением, и записать его
  нужно один раз. Баланс — размеры потоков: справочник «потоки в прогоне X» из сейва (ваниль против мегапака).
- **Мод** — те же слои для своего, плюс справочник «что меняет в ванили» (генерат) и у механик и потоков ключи `uses` /
  `replaces` на ваниль; карточка объекта мода — только если мод его добавляет или меняет, у изменённого — разница с
  ваниль по полям. У механики и потока ваниль таблица Bases «кто трогает» собирает все моды — предмет компача.
- **Имена** ([[Д.ДОК.22 — имена заметок источников|Д.ДОК.22]]): папка по источнику и типу (`vanilla/Здания/Шахта`), имя из русской локализации,
  нет её — английское, ключ — в `aliases`; одинаковые имена у источников — ссылки хвостом пути. Проверить, как Obsidian
  держит тысячи одноимённых файлов.
- **Что уже есть** — источник, но с пометкой «из <документа>, не сверено» до сверки с файлами
  ([[Как писать]]): документы форка (`mechanisms.md`, `money-model.md`, `entry-points.md`, `construction.md`),
  понятия форка о деньгах («Сверка по запасам», «Проводка», «Группа населения»), исследование E&F 24.09, дамп
  script_docs. Про ваниль — в граф ваниль, про E&F — в граф E&F, про форк — в форке. Навыки vic3tools остаются
  навыками: «как игра грузит моды» — навык, «как работает стройка в 1.13» — механика ваниль.

## Правки методики

Кандидаты (шаг 1), каждая — коммит в `docs/methodology/` и решение:

- **проект из нескольких репо**: узел (план, этапы, сквозные понятия, окружение, уроки, методика); правило размещения
  — документ в репо того, что описывает; «документ в одном коммите с кодом» — внутри репо; ссылки между репо держит
  проверка узла;
- **документ кода мода** — по подсистемам в `docs/`, `paths` — маски файлов игры: игра перебирает папки целиком, в
  Workshop уходит папка мода;
- **граф внешнего источника**: справочник «как сделано» вместо «как должно быть», ключи `source`, `uses`, `replaces`,
  разделы «Как работает», «Что меняет в ванили», «Не выяснено»; слои термины / объекты / области / механики / потоки;
- **генерат с ручным разделом**: `generated` у файла, ручной раздел генератор сохраняет; проверка не трогает генерат;
- **поток** как вид заметки (или вариант понятия) со сверкой по сейву (`verified_by`);
- **язык репо**: публичный продукт на своём языке, план и решения — на языке проекта.
