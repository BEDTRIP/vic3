# vic3 — документы

Моды Victoria 3: узел `vic3` и четыре репо. Документы ведутся по [[methodology/README|методу]]
([[Проект из нескольких репо (polyrepo)]]); на действующий метод — задачи, ADR — переведены 20.11
([[DOCS-1 — Перевод документов на метод ca31a1d|DOCS-1]]).

| вопрос | где |
| --- | --- |
| что сейчас, что ждёт меня, какие этапы | [[docs/план/README\|план]] — состояние, этапы, очередь человека |
| всё по этапу (все репо) | файл этапа в `план/` — цель, вопросы, порядок, задачи видами |
| одна работа | задача в `план/задачи/` — [[docs/план/задачи/README\|области и ключи]] |
| почему так — сквозное | `решения/` — [[docs/решения/README\|ADR узла]] |
| почему так — в форке | `Economic-and-Financial-Ledgerdemain-Mod/docs/решения/` |
| как вести документы и работу | [[methodology/README\|метод]] |
| форк: понятия, код, история | `Economic-and-Financial-Ledgerdemain-Mod/docs/` — вход `docs/README.md` форка |
| пачка: справочник набора, история | `vic3_mods/docs/`, вход в репо — [[vic3_mods/README]] |
| ваниль и чужие моды: термины, сводки, графы | `vic3_mods_out/docs/` (репо `vic3_out_docs`) — вход его `README.md` |
| инструменты | `vic3_tools/README.md`, [[vic3_tools/docs/usage]] |
| как было | [[docs/история/README\|история узла]] — закрытые этапы, снимки этапов до задач |

Раскладка узла: `план/` (план, этапы, `задачи/`), `решения/`, `история/`, `methodology/`; появятся `понятия/`
(сквозные: пачка, компач, плейсет, мост, ВМ, прогон, ночь), `devices/` (ПК, ВМ, ComfyUI, Steam), `уроки/`.
