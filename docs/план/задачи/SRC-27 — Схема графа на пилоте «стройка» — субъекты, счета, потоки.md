# SRC-27 — Схема графа на пилоте «стройка» — субъекты, счета, потоки

По [[ADR-0338 — граф — субъекты, счета, потоки, механики, рычаги, события|ADR-0338]]: в `vanilla/` — заметки субъектов стройки (страна, штат, строительные сектора, рынок, население,
инвестиционный пул) и их счетов (деньги казны, пул, очки стройки, запасы стройматериалов на рынке); потоки пилота —
`from` / `to` / `account` / `levers` в шапке, ссылки в тексте вместо слов; механика «Стройка» — `flows`; термины и
карточки генерата — ссылками. Где субъект совпадает с термином игры («Казна», «Рынок») — решить при работе: своя
заметка со ссылкой на термин или ручной раздел термина; выбор — в ход.

## Проверка

- в Obsidian от потока «Казна оплачивает стройку» кликом доходишь до казны, строительных секторов, закона и метода;
- граф стройки в Obsidian показывает субъекты, счета и потоки связанными; `v3 docs check` — 0 находок.
