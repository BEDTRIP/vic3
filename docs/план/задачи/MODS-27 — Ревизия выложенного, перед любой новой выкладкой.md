# MODS-27 — Ревизия выложенного, перед любой новой выкладкой

**Ревизия выложенного, перед любой новой выкладкой** (пользователь 16.10): всё, что уже в мастерской,
привести к одному стандарту. Выложено (ID в `metadata.json` живых копий, 16.10) — 21: мегапаки `megapack`,
`no t&r`, `no tgr`, `no e&f no psc`; аддоны Grey's, HC+GoB+MoH, LLWA, VC; компачи `ef+vc`, `greys+addon-vc`,
`greys+hc`, `greys+vc`, `morg+vc`, `tgr+tr+kai`, `tgr+vc`, `ComPatch E&F + Morgenroete`, `ComPatch E&F + The Great
Revision`; `E&F Hotfix`; переводы `E&F V4 RUS`, `The Great Revision RUS`. Для каждого:
- **жив ли:** нужен ли после форка (хотфикс и компачи с E&F снимаются — [[MODS-28 — Мастерская — перезалить сборки под форк|MODS-28]]), иначе — снять / пометить устаревшим
  со ссылкой на замену;
- **метаданные:** название и `short_description` по одному образцу, одна схема версий (сейчас вперемешку
  `1.13.11-1`, `1.13.11.1`, `1.13.1`, `1.13.0-1`, `v4.1.7`, `2.0`), `supported_game_version`, теги, зависимости
  (`relationships`) и ключ `vic3tools` (ID мастерской, ссылки на связанные моды и коллекцию);
- **содержимое:** что лежит в предмете — сейчас живая копия уходит целиком, с `README.md`, `_to_delete`, разборами
  конфликтов; перезалить чистой сборкой `v3 release build` (без мусора);
- **описание:** блок «Для мастерской» README сборки по правилам (`Правила — проект.md`, раздел 3, `tools/steam desc
  rules.txt`) — одинаковая структура (что это, порядок загрузки, зависимости со ссылками, что внутри, ссылка на
  коллекцию), английский + русский; превью ≤ 1 МБ у всех (у LLWA нет `thumbnail.png`);
- **коллекции:** какие нужны (весь набор, без T&R …), ссылки на них из описаний; под каждую — zip `v3 release zip`.
Итог — таблица «предмет → решение → что поправить» здесь, потом выкладка по ней через `v3 release` (каждая — с
подтверждением; описание — после одобрения разницы).
