# SRC-1 — Дамп движка 1.15 и справочник движка

Снять `script_docs`, `dump_data_types`, `dump_tweakables` без модов на ПК (навык `vic3-sandbox`, локальный режим;
[[ADR-0329 — дамп и прогоны ночи — на ПК, без ВМ|ADR-0329]]), положить в `graph.toml` (`dump`, `dump_date`), убрать
`dump_version = "1.13"`, `v3 graph all`, коммит `vanilla/движок`. Без дампа справочник движка в графе — 1.13 (13.10,
с E&F), и [[FORK-6 — Справочник движка 1.15|FORK-6]] (эффекты форка против 1.15) не начать.

Почему стоит: ночная сессия идёт от `worker` в сессии 0 Windows без экрана — окно игры на рабочий стол пользователя
(сессия 1) не вывести; мост `vic3-pc` в сессии 1 не запущен, ВМ по [[ADR-0329 — дамп и прогоны ночи — на ПК, без ВМ|ADR-0329]] не используется. Подробно — [[Этап ОБН. Обновление источников — до задач#Шаги|снимок этапа, «Шаги»]],
шаг 2.
