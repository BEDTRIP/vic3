# FORK-31 — Пять окон ваниль, которые форк подменяет целиком, — под 1.15.2

Форк кладёт `gui/construction_panel.gui`, `gui/country_panel.gui`, `gui/market_panel.gui`, `gui/states_panel.gui`,
`gui/texticons.gui` тем же путём, что ваниль, — игра берёт файл форка целиком, и всё, что ваниль поменяла с 1.13, в
этих окнах пропадает. Только с 11.11 (1.15.0 → 1.15.2): `construction_panel` +16 −14, `country_panel` +17 −9,
`market_panel` +604 −397, `states_panel` +93 −74, `texticons` +680 −323 строк ([[SRC-6 — Снимок источников и граф на 1.15.2|SRC-6]]); с 1.13 — больше.

Два пути: трёхстороннее слияние (база — ваниль 1.13 из истории снимка, наше — файл форка, их — ваниль 1.15.2;
навык `vic3-compat`) или вернуть ваниль и оставить в форке только свои типы — так задумано в R10
([[FORK-12 — Архив старого интерфейса E&F|FORK-12]], [[ADR-0282 — Старый интерфейс E&F — в архив целиком, новый — заново|ADR-0282]]).
Для форка на 1.15 — минимум: слить, чтобы окна ваниль работали; что из правок E&F в них живо — сверить с [[FORK-12 — Архив старого интерфейса E&F|FORK-12]].

**Решено ([[ADR-0340 — пять окон ваниль в форке — трёхстороннее слияние до R10|ADR-0340]]):** трёхстороннее слияние сейчас.

## Проверка

- игра 1.15.2 с форком: окна стройки, страны, рынка, штатов открываются без ошибок `gui` в `error.log`;
- снимки окон стенда `v3 bench` в ВМ против ваниль — новое 1.15 на месте.
