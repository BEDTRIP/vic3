## Цели и принципы

Моды Victoria 3: свой самостоятельный экономический мод — форк E&F «Ledgerdemain» (зависимости — CMF и ETF) — и
набор модов вокруг него (компачи, мегапаки, аддоны), выложенные в мастерскую; инструменты `v3`, на которых это
держится.

- Сначала самостоятельный форк, потом пачка (пользователь 7.10). ^p1
- Компачи и решения о чужих модах — по графу источников: что мод меняет в игре, видно из сгенерированных заметок, а не
  из памяти ([[ADR-0310 — документация источника — справочник|ADR-0310]]). ^p2
- Игра, а не тест, — мерило: этап форка закрывается прогоном (Швейцария до 1847), ошибок по файлам форка — 0. ^p3
- Главное — правильный ответ; путь к нему агент выбирает сам (пользователь 16.10). ^p4

## Как идёт работа

Метод — [[Этап (epic)]], [[Задача (issue)]], [[Закрытие этапа (epic closure)]], [[Проект из нескольких репо (polyrepo)]].
Отличия проекта:

- **Области задач** — по репо: `FORK` (форк), `MODS` (пачка `vic3_mods`), `TOOLS` (`vic3_tools`: `v3`, мост,
  плагин), `SRC` (снимок и граф источников `vic3_mods_out`), `DOCS` (документы узла и метод) —
  [[docs/план/задачи/README|файл папки задач]]. Пути в `touches` — от папки узла (`Economic-and-Financial-Ledgerdemain-Mod/gui/`).
- **Коммиты:** код — в своём репо, файл задачи — в узле; в ходе задачи — репо и хеш (`форк a1b2c3d`). Сообщение — с
  ключом задачи в начале, по-русски; в теле — что было сломано, как это выглядело в игре, почему так.
- **Прогоны игры** — в ВМ-песочнице ([[ADR-0332 — прогоны и дамп — в ВМ-песочнице, игра в ней — копией с ПК|ADR-0332]]). **Без человека** — `/loop` по методу
  ([[Ночная работа (multi-agent night run)]]); своих навыков ночи нет (пользователь 20.11).
- **Закрытие этапа форка**, кроме метода:
  - проверочный прогон — новая игра за Швейцарию до конца 1847 (пользователь 12.10: прогоны сравнимы по годам); пока
    механики не сбалансированы — рабочие прогоны по 5 лет до конца 1840; скорость (`v3 log speed`) и профиль —
    записать для R11, условием закрытия не служат ([[ADR-0118 — Скорость — не условие закрытия этапа|ADR-0118]]);
    `v3 log diff` против базы CMF + ETF; ошибок по файлам форка — 0;
  - `ld_smells.py summary` до и после; `v3 lint`, `ld_index.py`, `v3 docs check` (из узла — все репо), генераторы с
    `--check`;
  - понятия области — по факту, документы кода (`docs/код/`) — по коду.
- **Сквозное форка без своей задачи:** правишь файл — снимай в нём дубли (С9), новые числа — сразу именованными (С10),
  комментарии-историю (С14). Дорогая строка без задачи: `$VALUE$` в `zz_ef_money_ledger_delta` (0,56 + 0,57 с
  профиля). Снимок аудита смеллов — [[2026-10-09 план до разбора по этапам]]; пересчёт — `ld_smells.py`.
- **Закрытые этапы** — [[docs/история/README|история узла]]; этапы форка до ДОК — история форка
  (`Economic-and-Financial-Ledgerdemain-Mod/docs/история/`, хронология — её `README.md`), пачки — `vic3_mods/docs/история/`.
