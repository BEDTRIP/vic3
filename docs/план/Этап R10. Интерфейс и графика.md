## Задачи

```base
filters:
  and:
    - type == "issue"
    - file.hasLink(this.file)
views:
  - type: table
    name: Открытые
    filters:
      and:
        - status != "done"
        - status != "wontdo"
        - status != "verified"
        - status != "invalid"
        - status != "duplicate"
        - status != "wontfix"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - question
      - answer
      - description
    sort:
      - property: date
        direction: ASC
    rowHeight: tall
    columnSize:
      file.name: 180
      note.question: 190
      note.answer: 130
      note.description: 200
  - type: table
    name: Архив
    filters:
      or:
        - status == "done"
        - status == "wontdo"
        - status == "verified"
        - status == "invalid"
        - status == "duplicate"
        - status == "wontfix"
    order:
      - file.name
      - status
      - verified_by
      - description
    sort:
      - property: date
        direction: DESC
    rowHeight: tall
    columnSize:
      file.name: 200
      note.status: 90
      note.verified_by: 160
      note.description: 250
```

## Definition of Done

- окна денег, верхняя панель и карточка страны — в игре, проверены на стенде в 2–3 темах и 11 языках (`v3 gui fit`);
- старый интерфейс E&F — в архиве, игра без ошибок `gui` по файлам форка;
- подсказки понятий и символ валюты — в игре; графика нужных окон — в ванильном стиле.
