## Задачи

```base
filters:
  and:
    - type == "issue"
    - file.hasLink(this.file)
views:
  - type: table
    name: Открытые
    filters:
      and:
        - status != "done"
        - status != "wontdo"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - question
      - answer
      - description
    sort:
      - property: file.name
        direction: ASC
    rowHeight: tall
    columnSize:
      file.name: 180
      note.question: 190
      note.answer: 130
      note.description: 200
  - type: table
    name: Архив
    filters:
      or:
        - status == "done"
        - status == "wontdo"
    order:
      - file.name
      - status
      - verified_by
      - description
    rowHeight: tall
    columnSize:
      file.name: 200
      note.status: 90
      note.verified_by: 160
      note.description: 250
```

## Definition of Done

- у ваниль — механики и потоки всех десяти областей, с размерами из прогонов ВМ;
- у каждого мода снимка — что он меняет в механиках ваниль (`uses` / `replaces`), у E&F — его собственные механики;
- `v3 graph all --check` и `v3 docs check` чистые.
