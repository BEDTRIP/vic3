# Этап ФГ. Форк на графе

## Цель

Форк почти ничего не добавляет к игре — он делает экономические взаимосвязи субъектов реалистичными:
детерминированный хаос самостоятельных участников вместо упрощений ваниль. Этот этап показывает это на графе
([[ADR-0337 — дорога проекта — граф ваниль, форк на графе, механики, интерфейс, моды по графу|ADR-0337]]): поверх графа ваниль ([[Этап Г. Граф ваниль]]) — какие связи форк меняет и добавляет, его собственные
механики и где реалистичных связей ещё нет. Итог — очередь механик, взаимодействий и событий для R11.

## Открытые вопросы

Нет.

## Задачи

```base
filters:
  and:
    - type == "issue"
    - file.hasLink(this.file)
views:
  - type: table
    name: Открытые
    filters:
      and:
        - status != "done"
        - status != "wontdo"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - question
      - answer
      - description
    sort:
      - property: file.name
        direction: ASC
    rowHeight: tall
    columnSize:
      file.name: 180
      note.question: 190
      note.answer: 130
      note.description: 200
  - type: table
    name: Архив
    filters:
      or:
        - status == "done"
        - status == "wontdo"
    order:
      - file.name
      - status
      - verified_by
      - description
    rowHeight: tall
    columnSize:
      file.name: 200
      note.status: 90
      note.verified_by: 160
      note.description: 250
```

## Definition of Done

- у понятий форка — `uses` / `replaces` на граф ваниль, схема «ваниль → форк»;
- механики и потоки форка в графе, сверенные с кодом и прогоном;
- очередь R11 выведена из сравнения графов.
