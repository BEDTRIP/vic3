# Этап Г. Граф ваниль

## Цель

Как устроена экономика ваниль: механики и потоки денег и товаров между субъектами (казна, население, здания,
компании, пул инвестиций, рынки) — целиком, с размерами из прогонов. На этом графе форк показывает, какие связи он
делает реалистичными ([[Этап ФГ. Форк на графе]]), и по нему же потом сводятся моды ([[ADR-0337 — дорога проекта — граф ваниль, форк на графе, механики, интерфейс, моды по графу|ADR-0337]]).

## Задачи

```base
filters:
  and:
    - type == "issue"
    - file.hasLink(this.file)
views:
  - type: table
    name: Открытые
    filters:
      and:
        - status != "done"
        - status != "wontdo"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - question
      - answer
      - description
    sort:
      - property: file.name
        direction: ASC
    rowHeight: tall
    columnSize:
      file.name: 180
      note.question: 190
      note.answer: 130
      note.description: 200
  - type: table
    name: Архив
    filters:
      or:
        - status == "done"
        - status == "wontdo"
    order:
      - file.name
      - status
      - verified_by
      - description
    rowHeight: tall
    columnSize:
      file.name: 200
      note.status: 90
      note.verified_by: 160
      note.description: 250
```

## Definition of Done

- у ваниль — механики и потоки всех десяти областей (и стройки), с размерами из прогонов ВМ;
- обзорная схема субъектов ваниль и потоков между ними;
- `v3 graph all --check` и `v3 docs check` чистые.
