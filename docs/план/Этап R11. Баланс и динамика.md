# Этап R11. Баланс и динамика

Разбор, решённое и ход до перевода на задачи 20.11 — [[Этап R11. Баланс и динамика — до задач|снимок этапа]].

## Цель

Система живёт сама: исключительные случаи (гражданские войны, война и размен, биржа при исключительных событиях,
переход штата), динамика стран (кризисы, паники, банкротства, переходы стандартов), баланс по прогонам 1850 / 1870,
технологии и институты, общая полировка и скорость. Понятия — [[Банкротство]], [[Инвестиционный фонд]], [[Биржа]],
[[Новая страна]], [[Рычаги на движок]], [[Обменный стандарт]].

Пауза с 29.10: стоит до конца [[Этап ОБН. Обновление источников|этапов ОБН]] и «Форк до 1.15» ([[ADR-0306 — пауза на время перехода|ADR-0306]], [[ADR-0326 — курс — ОБН, потом форк на 1.15|ADR-0326]]); возобновляет пользователь. Пути в задачах (`docs/…`, `common/…`, `tools/…`) — от корня форка.

## Задачи

```base
filters:
  and:
    - type == "issue"
    - file.hasLink(this.file)
views:
  - type: table
    name: Открытые
    filters:
      and:
        - status != "done"
        - status != "wontdo"
        - status != "verified"
        - status != "invalid"
        - status != "duplicate"
        - status != "wontfix"
    groupBy:
      property: status
      direction: ASC
    order:
      - file.name
      - question
      - answer
      - description
    sort:
      - property: date
        direction: ASC
    rowHeight: tall
    columnSize:
      file.name: 180
      note.question: 190
      note.answer: 130
      note.description: 200
  - type: table
    name: Архив
    filters:
      or:
        - status == "done"
        - status == "wontdo"
        - status == "verified"
        - status == "invalid"
        - status == "duplicate"
        - status == "wontfix"
    order:
      - file.name
      - status
      - verified_by
      - description
    sort:
      - property: date
        direction: DESC
    rowHeight: tall
    columnSize:
      file.name: 200
      note.status: 90
      note.verified_by: 160
      note.description: 250
```

## Definition of Done

- прогоны 1850 / 1870: деньги, кредит, банки, биржа живут без ручных правок; кризисы случаются и проходят;
- ошибок по файлам форка 0; скорость и профиль записаны для R12;
- новый аудит смеллов снят.
