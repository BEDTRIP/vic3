# SRC-19 — Механики PSC — стройка целиком

Что описать: пилот «стройка» PSC — до всей механики. По образцу пилота «стройка» (принятому в [[SRC-3 — Разбор пилота «стройка» и принятого ночью 12.11|SRC-3]]): механика — «Суть», «Как работает», «Рычаги»,
«Стоимость», «Где», «Не выяснено»; поток — заметка на движение денег или товаров с размером из прогона
([[Внешний источник (vendoring)]]). Своё поверх ваниль — в графе мода с `uses` / `replaces` на механики ваниль; пересказа ваниль нет.
Прогоны — в ВМ-песочнице ([[ADR-0332 — прогоны и дамп — в ВМ-песочнице, игра в ней — копией с ПК|ADR-0332]]).

## Проверка

- механика и потоки в `vic3_mods_out/docs/`; у потоков — размеры с `verified` на прогоне или «не сверено» с причиной;
- `v3 docs check` из узла — 0 находок.
