## Как идёт работа

Этап — по [[methodology/Этап|методике]], закрытие — [[methodology/Закрытие этапа|закрытие этапа]]. Отметка шага —
коммит в узле, код — коммит в своём репо ([[Проект из нескольких репо]]). Порядок у этого проекта:

1. **Решения — днём.** Прочитать файл этапа и понятия его области (сверить с кодом). Вопросы из «Решить до кода» и
   найденные по ходу — пользователю, с вариантами и рекомендацией первой. Ответ — файлом решения в `docs/решения/`
   своего репо (`Д.<этап>.N`, сквозное — в узле), правка заметки понятия — в том же коммите; в файле этапа — «Решено
   (Д.N)» вместо вопроса.
2. **Работа — ночью**, новой сессией по навыку `night-run` (несколько этапов до срока — `night-until`). Ночной раздел
   («Ночь»: особые правила, ход) — в файле этапа.
3. **Шаг:** сделать → проверить → коммит и `git push` → в файле этапа у пункта — «✅ дата, репо и коммит», цифры.
4. **Закрытие** — по [[methodology/Закрытие этапа|методике]], плюс у этапов форка:
   - проверочный прогон — новая игра за Швейцарию, до конца 1847 (пользователь 12.10: окна «за 10 лет» видны, прогоны
     сравнимы по годам; дальше 1847 не крутить, пока механики не сбалансированы; навык `vic3-sandbox`); пока — рабочие
     прогоны по 5 лет, до конца 1840 (пользователь 12.10): скорость (`v3 log speed`) и профиль — записать для R11,
     условием закрытия не служат (Д.R8б.31), `v3 log diff` против базы CMF + ETF; ошибок по файлам форка — 0;
     проверки этапа — раздел «Закрытие» файла этапа;
   - `ld_smells.py summary` до и после; `v3 lint`, `ld_index.py`, `ld_docs_check.py`, генераторы с `--check`;
   - понятия области — по факту, документы кода (`docs/код/`) — по коду;
   - файл этапа → `docs/история/` узла (`type: history`, `kind: phase`, `date` — дата закрытия) с «Итогом» в начале:
     что сделано (коммиты), цифры прогона, смеллы до / после, куда что перенесено; в таблице выше — «закрыт» со
     ссылкой; «Состояние» — переписать.

**Сквозное, без своего этапа (форк):** правишь файл — снимай в нём дубли (С9), новые числа — сразу именованными
(С10), комментарии-историю (С14). Дорогая строка без этапа: `$VALUE$` в `zz_ef_money_ledger_delta` (0,56 + 0,57 с
профиля). Снимок аудита смеллов со столбцом «что сделано» — [[2026-10-09 план до разбора по этапам]]; пересчёт —
`ld_smells.py`.
